# Project Brief

Build a modern BMI calculator web app using HTML, CSS and JavaScript.

## Scope (current requirements)
- Pure client-side static web app — HTML, CSS, vanilla JavaScript (no build step, no framework).
- Web and mobile friendly: responsive layout, touch-friendly controls, dark mode, offline-capable via service worker.
- Metric (kg/m) and imperial (ft/in + lb) input with WHO category classification.
- Zero backend dependency: BMI calculation runs in the browser; works offline and on any static host (GitHub Pages, etc.).
- Accessible: semantic HTML, labels, `inputmode`, ARIA live region for results, reduced motion support.

## Out of scope (removed)
- .NET / ASP.NET Core backend API.
- React, TypeScript, Tailwind, Entity Framework Core, PostgreSQL.
- TanStack Query, server-state management, DI container.
- Swagger/OpenAPI, controllers, migrations.
